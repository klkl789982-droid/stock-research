# 두 목적 EOD 연구 v1

사전 계획은 config/dual-target-study-v1.json (790b3ec). 결과는 운영 성과가 아니라 사후 재구성이다. scripts/run-dual-target-study.mjs로 집계 파일을 재생성한다. 시세·학습 행·개별 종목 순위는 새 파일로 내보내지 않는다. 최신 연구 순위는 인증된 서버에서 최신 날짜의 seed로 계산하며 학습 마감과 순위 기준일을 구분한다.

|---|---|---|
|A-v1 기술 강도|이평, RSI/MACD, 거래량, 모멘텀, 변동성, 반전 보너스와 위험 감점|동일 공식 hash·품질 인증 일별 원순위/점수. 새 학습 특징으로 중복 합산하지 않음|

전체 553개 현재 구성의 공식 11-02 seed에 종목당 최대 260일이 있다. [금융위원회 API](https://www.data.go.kr/data/15094808/openapi.do)의 기존 캐시·페이지 조회를 재사용할 수 있으나, 동일 기간을 다시 내려받아도 상장폐지 종목·과거 구성·공시 시각은 복구되지 않는다. 2026년에 확인한 세율과 KRX 휴장표 범위로 제한한다. 1월의 최초 20거래일은 워밍업. 당시 선정 자료가 없는 날짜에 A~D 순위를 지어내지 않는다. 실제 LIVE는 혼합하지 않는다.

조건부 추정치는 날짜마다 동일 가중, 특징별 단면 5구간에 관측된 전체 이후 수익률 또는 상승 사건으로 학습한다. 2일 상당 축소와 인접 구간 보간만 사용한다. 다특징은 추정치를 평균한다. 가중치·이평 기간 탐색 없음. 큰 수익을 상한으로 자르거나 손실 사례를 빼지 않는다. 화면 점수는 같은 날짜 후보 내 백분위이며 동점은 코드순이다. 방향은 close > open, 비용 후 이익은 비용 적용 매도가치 > 매수가치로 별개다. 5월/7월/9월 경계보다 먼저 청산된 행으로만 적합하고 평가도 블록 경계에서 청산되지 않으면 제외한다. 이미 본 기간이고 보유 구간이 겹친다. 날짜 수는 독립 베팅 수가 아니다.

비교 표의 기본률은 날짜별 평가 가능 종목 전체의 가격 상승 비율이다. BASE의 예측은 학습 구간 기본률, 동률 TOP은 코드순으로 경제적 의미가 없다. A~D는 확률이 아니므로 Brier/log loss를 만들지 않는다. 일별 TOP 통계는 선정 후 10/20개 전부의 가격이 있는 날만 계산한다. IC·오차는 평가 가능한 쌍만 사용한다. 계좌는 종목을 고른 뒤 실제 현금/슬롯 제약을 적용하며 결측 보유 평가액은 미확인 처리한다. TOP의 평균 수익률은 계좌 수익률이 아니다. 업종 이력·배당·미세한 기업행사·실제 주문 체결은 검증하지 못했다.

9월 이후 A~D 공통 비교는 모든 버전의 인증 순위가 있는 날짜·종목만 쓴다. 게시 시각 비교는 기존 검증 영수증의 시각과 seed 생성 시각 중 늦은 시각 후 첫 정규 시가, 같은 진입일은 최신 신호 하나. 당시에 이 두 새 후보가 게시됐다는 뜻이 아니다. 각 후보·fold·제외 특징 진단과 실패 결과를 집계에 함께 보존한다. 추가 검증은 고정된 후보로 새 날짜를 수집하고, 기업행사·당시 구성·업종을 확보한 뒤 시장 국면별·거래일 블록별 결과를 점검하는 것이다. 자동 승격 없음.
